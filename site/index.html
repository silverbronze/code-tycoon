Task manager

Hand off tasks. Get reports back. Answer only when it needs you.

Write down what you want done, for any project, in one place. Code Tycoon routes each task to its project and runs it as a real session you can watch.

  • Paste a whole list

    It splits the list across projects, finds the right project for each task, and queues one run per project at a time.

  • Big tasks run as a plan of steps

    Each step is checked off as it lands. Turn on "pause after each step" if you want to look before it goes on.

  • "Needs you" is your to-do list

    Decisions, a secret to put somewhere, a manual step, or a command it was not allowed to run. Answer it and the same session picks up where it stopped.

  • A report for every finished task

    What changed, what was checked, and anything left for you, in a few lines.

Questions people ask first

Will my own skills and setup really work there?

Yes. Your server runs the same Claude Code and Codex you run at home, with your skills, CLAUDE.md files, MCP servers, hooks and permission rules. Sessions behave the way they do on your laptop.

Where does my code live? Who can see it?

On your own dedicated server, which isn't shared with anyone else, behind a login. If you'd rather nothing left your machine, host Code Tycoon yourself: it reads everything locally and has no account.

Which models can I use?

Claude Code with Opus, Sonnet or Haiku, and Codex with OpenAI's models. Code Tycoon picks up sessions from both, prices them, and shows them side by side.

Do I still need my own Claude or ChatGPT plan?

Yes. The plan pays for your server; the models run on your own Claude subscription, ChatGPT subscription or API key, the same ones you use today. Code Tycoon shows you what each task cost, so you can see where that usage goes.

What happens when a task needs me?

It goes to "Needs you": a decision, a secret to put somewhere, a manual step, or a command the session wasn't allowed to run. Answer it from any device and the same session carries on. Steps that don't depend on your answer keep going meanwhile.

Can I see what a session is doing while it runs?

Yes. Every task runs as a real session that shows up on the city and the domain map, in the task log and on the dashboard. You can open it, follow it, or stop it.

Can I host it myself instead?

Yes. Code Tycoon is open source under AGPL-3.0. Run npx code-tycoon on your machine or your own server; the source and setup notes are on GitHub. Live updates add a hook to ~/.claude/settings.json after backing it up, and npx code-tycoon hooks uninstall removes it.

Is it made by Anthropic?

No. Code Tycoon is an independent project, not made or endorsed by Anthropic.
