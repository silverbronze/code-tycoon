# Code Tycoon logo

One isometric tower whose lit windows are lines of nested code.

| File | Use |
|---|---|
| `logo.svg` | primary horizontal lockup, ink `#0B0F1A` (uses `currentColor`) |
| `logo-dark.svg` | on dark backgrounds: gold `#F2B23E` mark, paper `#F4F1EA` word |
| `logo-stacked.svg` | stacked lockup |
| `logo-mono.svg` | one flat colour (black) |
| `mark.svg` | the mark alone, for 32px and up |
| `mark-small.svg` | simplified mark (3 windows, wider cuts) for 24px and below |
| `favicon.svg` | gold small mark on an ink tile (copy in `web/public/`) |

Wordmark: Space Grotesk Bold (SIL OFL) converted to outlines. Clear space: one cap height on all sides.

- Keep the windows ragged; regularised, the tower reads as a "server" icon.
- Never hyphenate, line-break or letter-space "tycoon".
